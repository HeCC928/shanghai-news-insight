# 沪讯 · 公司资讯与估值研究助手

**从公司新闻，到可以追问、调整与复算的估值判断。**

一个面向沪市 A 股的金融科技研究工作台，将行情、新闻证据、DeepSeek 分析和交互式 DCF 放进同一个产品界面。

## 项目解决什么问题

公司研究往往需要在新闻、财报与估值表之间来回切换。沪讯把流程连起来：先查看公司信息和证据，再修改经营假设、比较估值，最后导出可追溯的研究结果。

**Python 负责计算，DeepSeek 负责解释。** 模型梳理经营机制、来源和不确定性；推荐标签由保存的 DCF 输入与带时点的报价比较产生。用户可以看见结论依赖什么，并实际改变假设验证它。

## 看图了解产品

### 新闻证据：从“发生了什么”到“如何影响经营”

提取事件与情绪，展示原始来源、经营影响路径和后续核查事项；区分行业背景与公司事实。

![新闻证据与经营影响分析](docs/screenshots/maotai-news.jpg)

### 交互估值：让假设的影响可见

五年 FCFF、悲观/基准/乐观情景、WACC×永续增长敏感性矩阵、保存版本与解释。完整估值工作台还支持收入增长、利润率等参数调整。

![交互式 DCF 与三情景估值](docs/screenshots/maotai-dcf.jpg)

茅台历史案例中，将 WACC 从 9% 调到 12%，每股估值由 1,439.21 元变成 990.82 元，报价仍为 1,237 元。这用于说明假设敏感性，不能证明哪个结果就是正确目标价。

### 专业提示词：把研究方法变成可编辑的流程

内置九套模板，覆盖公司研究、新闻提取和估值解释。可关注买方研究、渠道与回款、反证风险、终值与资本成本；支持编辑、保存版本和试运行。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 公司研究 | 公司搜索、自选、历史价格、经营概况、支持因素、风险与来源 |
| 新闻分析 | 筛选、事件与情绪提取、原文证据、经营影响、最多二十篇批量导入 |
| DCF 估值 | 五年现金流、终值再投资、股权桥接、三情景、敏感性、版本保存 |
| Agent 追问 | 在当前公司及报告证据范围内调用工具，回答研究问题 |
| 提示词 | 九套专业模板、可编辑偏好、版本记录和试运行 |
| 演示研究室 | 读取提前生成的茅台内容，切换不再调用模型，DCF 本地复算 |
| 导出 | Markdown 研究报告、估值和新闻 CSV |

## 快速运行

支持 Windows PowerShell，需安装 Python 3.11+、Node.js 22+。开发实测环境为 Python 3.13、Node.js 24。首次安装依赖需要联网。

下载并解压，进入项目根目录：

```powershell
.\scripts\setup.ps1
.\scripts\start.ps1
```

打开 **http://127.0.0.1:3000**，API 文档位于 **http://127.0.0.1:8010/docs**。

默认提供五家虚构公司，涵盖低估、高估、合理、数据不足与不适用场景。**无需密钥即可体验**；安装完成后演示模式不依赖外部数据请求。

停止服务：`.\scripts\stop.ps1`。使用正式预览时先停止服务，再执行：

```powershell
npm.cmd --prefix frontend run build
.\scripts\start.ps1 -Production
```

### 开启 DeepSeek 真实研究

安装脚本会在缺少 `.env` 时复制 `.env.example`。在根目录 `.env` 填写 `DEEPSEEK_API_KEY`，重启后端，在设置中切换真实公司研究。模型与接口地址均可配置；密钥仅由服务端使用。

真实模式需要网络、可用数据源和模型账户余额。财务缺项需要填写来源与核查理由，金融机构不适用当前非金融 FCFF 模型。

### 提前准备茅台演示

服务运行、密钥配置且财务输入通过核查后：

```powershell
.\.venv\Scripts\python.exe scripts\prepare_presentation.py
```

完成后访问 **http://127.0.0.1:3000/presentation**。此操作会调用 DeepSeek、启用茅台提示词并保存结果；同一天重复执行会复用已完成步骤。

**源码包不包含作者本地数据库和茅台实时数据缓存。** 新安装的演示研究室在准备完成前显示空状态；无需密钥的体验请先使用普通研究台中的虚构公司。

## 实现与验证

- 前端：Next.js、TypeScript、TanStack Query、ECharts、Tailwind 与 Radix。
- 后端：FastAPI、Pydantic、SQLAlchemy、Alembic、SQLite。
- 数据适配：上交所公司列表、腾讯行情、东方财富新闻/财报与 AKShare。
- Agent：DeepSeek 结构化输出、来源白名单、受控数字占位符、报告范围内工具调用。
- 工程：持久化任务、SSE 进度与轮询恢复、失败阶段、超时边界、不可变研究快照。

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
npm.cmd --prefix frontend run build
npm.cmd --prefix frontend run typecheck
```

## 范围与限制

本项目为本地单用户研究原型。免费数据可能延迟或失败，新闻常为摘要。历史增长外推、资本成本、营运资本与股权调整都涉及判断，三情景不是置信区间；2026 年以外交易日历需更新。

项目不包含回测、自动交易、券商账户或已验证的收益预测能力。公网多人部署需另行补齐认证与运维能力。第三方数据和依赖保留各自条款；仓库暂未附项目整体授权许可证。
