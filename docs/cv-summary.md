**Shanghai News Insight | Full-stack FinTech Research Product**

- Built a responsive equity-research terminal integrating Shanghai A-share prices, news, watchlists and an interactive five-year FCFF valuation workspace with scenarios, sensitivity analysis and versioned exports.
- Integrated DeepSeek for structured news extraction, evidence-linked research and bounded tool-assisted follow-ups; kept valuation calculations and recommendation rules deterministic and independent of generated prose.
- Implemented source snapshots, TTM normalization, explicit assumptions and missing-data handling; validated the system with 54 automated tests and a live-company research workflow using sourced manual financial adjustments.

技术栈：Next.js / TypeScript / ECharts / FastAPI / Python / SQLite / DeepSeek API。

可选面试指标：本机20次DCF含场景/矩阵请求P95为7.23ms；一次缓存数据真实研究6.13秒。同时说明环境、样本规模与失败记录，不当作生产SLA。
